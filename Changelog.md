# SlotGuard 1.0.1

* Added config option to toggle the visibility of padlock icons on the hotbar.
* Added config option to toggle the ability to use slotguard keybinds when not in inventory.
* Added support for the Endless texture pack.
* Fixed slotguard keybinds being blocked while typing in inventory text fields.
* Fixed the off-hand padlock icon not appearing on the hotbar.
* Fixed incorrect capitalisation in the README header
